REGISTRO DE HÁBITOS — VERSIÓN DE TERMINAL
=========================================

CONTENIDO
- INICIAR_TERMINAL.bat: inicia la aplicación en Windows.
- Registro_De_Habitos.py: aplicación de consola.

INICIO
1. Extrae esta carpeta completa.
2. Verifica que Python 3 esté instalado y disponible como py o python.
3. Abre INICIAR_TERMINAL.bat.
4. Escribe un nombre de usuario para separar los archivos de datos.

DATOS Y RESPALDOS
Al iniciar, la aplicación crea data/terminal dentro de esta carpeta y guarda allí un archivo JSON por usuario. Los reportes TXT y respaldos JSON se crean en reportes/. Estas carpetas aparecerán al usar esas funciones.

Esta versión funciona de manera independiente y no sincroniza sus registros con la versión web. Puede crear un respaldo JSON que la versión web puede importar. La terminal no incluye una función para importar respaldos.

El nombre de usuario separa archivos, pero no es una contraseña ni un mecanismo de autenticación. Mantén los respaldos en un lugar seguro.
